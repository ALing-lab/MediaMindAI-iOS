## 三、核心业务链路与关键能力（截至 `ui-v56`）

1. **多网盘接入与安全凭据**
   - 原生支持 **光鸭云盘**（手机号 + 短信验证码 + 人机校验）、**123 云盘**（账密登录 + `moveBatch` 批量移动）、**WebDAV / OpenList**（支持 TOFU 自签名证书指纹确认）。
   - 支持多账号管理与**自定义账号备注名**（`customLabel` 防重登覆盖且不破坏 `AccountBinding` HMAC 签名）。
   - 浏览网盘支持面包屑跳转、顶部「`< 上一级`」按钮、列表首行/空目录「返回上一级」入口、常用目录收藏与非阻塞后台扫描。

2. **混合识别与命名规则**
   - **去混淆与双语识别**：剥离网站广告 `【...】`、压制标签 `[...]`、穿插 `=` 符号；双语片名优先中文权重并触发无年份回退（解决多季国产剧首播年与当前季年份不一致导致的英文同名剧误匹配）；剧集豁免续集扣分。
   - **AI 辅助与本地蒸馏**：TMDB 常规检索未命中时按预算调用 AI 兜底，核实后自动沉淀至「本地蒸馏规则库」（支持独立筛选、搜索、滑动删除与清空）。
   - **剧集多策略**：支持「默认策略」「单季顺序拆多季」「单季跳序拆多季」「多季合并一季」及 TMDB 自定义剧集组（Episode Group）。

3. **三级策略体系与精细控制**
   - **第 1 层 · 全局策略**：主总开关（启用文件整理 / 启用海报与 NFO 刮削）、`整理季目录`（已接通禁用季目录创建/重命名/移动）、`合并同系列（电影合集 / 同剧多季）` 总开关、`目标库归档与重复处理`（仅全局保留）。
   - **第 2 层 · 任务策略**：预览页底部「任务策略」胶囊触发；仅当全局打开「合并同系列」时，展示独立的「合并同系列（电影）」与「合并同系列（剧集）」双开关；支持实时命名/刮削覆盖。
   - **第 3 层 · 影片策略**：作品详情页按单部作品覆写，实时预览并重算动作。
   - 表单内所有下拉选项采用 `OptionSheetPickerRow`（原生底部选项表），规避 iOS 26/27 Liquid Glass 下 `.menu` Picker 收起后文字滞留不随滚动的系统问题。

4. **归并、拆分归档与预览交互**
   - **同系列电影大文件夹拆分归档**：开启自定义目标媒体库时，自动将系列大文件夹内的每部电影独立建子文件夹归档至 `目标库/电影/<片名 (年份) {tmdb-ID}>/`，确保 Emby / Infuse / VidHub / 爆米花 / Kodi 正常刮削聚合。
   - **跨目录同剧多季自动提级平铺**：合并不同文件夹的同一部剧集时，自动将 `Season XX` 子目录或散落集数直接提级/重定向至主剧集目录下形成 `主剧目录/Season 01` + `Season 02`，不套多余外层目录。
   - **预览卡片与多版本聚合**：支持「已识别 X 季 Y 集 | 共 A 季 B 集」展示、双行目录路径（头部截断路径 + 尾部截断文件夹名）、多版本按集聚合（标题 + `多版本` 标签 + 规格差异胶囊）、详情页每季海报横向滑切与单集缩略图展示。
   - **任务驱动预览**：底栏仅云盘 / 任务 / 设置；扫描完成后任务中心进行中显示待执行卡，点击预览按计划 ID 全屏打开识别结果页。搜索位于预览页右上角圆形放大镜。

5. **五阶段可逆执行与安全兜底**
   - 严格 5 阶段执行顺序：① 重命名（目录先于文件）→ ② 新建文件夹 → ③ 移动（123/光鸭支持 `moveBatch` 批量移动）→ ④ 上传海报与 NFO（不含 `season.nfo`）→ ⑤ 删除多余空目录。
   - 全程写入 `ReversibleWalStore` 与 `OperationJournal`，支持网络不确定时自动停机保护、`JournalReconciler` 核实对账、按逆序安全回滚、以及「重复保留区」二次复验后清理。

## 十六、限流重试与自动云端核实（2026-11-27，工作区未打包）

### 已接线的恢复流程

- 串行、并发波次、批量移动统一进入有限恢复流程。发生可恢复错误后最多两轮，分别设置 2 秒、5 秒退避；驱动内部等待／重试与网络耗时另计。限流会同步降低当前并发。自动恢复沿用本次执行记录，不创建新任务卡；用户手动“重试失败／未完成项”仍创建关联的新尝试。
- 并发波次先收齐在途结果，再核实本次执行的正向 WAL。只读检查账号、源／目标位置、对象身份及可用大小／ETag／MD5，不使用同名猜测，也不自动处理撤销记录。确认已成功的步骤只补本地映射／保留区登记；确认未生效后才重试，成功项不重发、不重复记数。
